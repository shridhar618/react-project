# React + Vite Practice Project

A beginner React 19 project set up with Vite, covering components, JSX, `useState` and a reusable navbar.

## Contents

- `src/App.jsx`: main component with state (`useState`) and a data table
- `src/componenta/Navbar.jsx`: reusable navigation bar
- `src/componenta/App2.jsx`: example functional component

## Tech stack

React 19 · Vite · ESLint

## Getting started

```bash
npm install
npm run dev
```
